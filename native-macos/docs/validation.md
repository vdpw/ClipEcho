## 系统 Go 环境验证

新的 `zsh -lc` 确认 Go 为 `/usr/local/go/bin/go`、Go 1.26.1 `darwin/arm64`，
clang 为 `/usr/bin/clang`（Apple clang 21.0.0，Apple CLT），`CGO_ENABLED=1`、
`CC=clang`。Swift 专用包装脚本不覆盖系统 C 编译器。

CGO 样例以及 ESP Service、ESP API、ESP Console 三个服务入口均实际编译通过。
其中 ESP Service 在现有工作区以 `GOPROXY=off`、`go build -mod=readonly` 编译
`./cmd/aira-aiplatform-esp-service`，生成临时目录中的 arm64 Mach-O 可执行文件。
验证未修改这些项目的源码、`go.mod` 或 `go.sum`，也未启动服务。

本地 Release 包默认省略 dSYM；正式发布需要调试符号时可使用
`CLIPECHO_DEBUG_SYMBOLS=1 ./scripts/build-app.sh release`。

本机验证不替代实际登录启动、另一设备 Universal Clipboard、Intel 目标电脑、更多
来源应用格式，以及 Developer ID 签名和公证。
